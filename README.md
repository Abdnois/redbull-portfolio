🔴 Red Bull Fan Portfolio
A responsive Red Bull–themed fan site with a product showcase, shopping cart, and checkout page. Built as a static site and deployed with GitHub Pages.

Unofficial fan project. Not affiliated with or endorsed by Red Bull GmbH. All trademarks, logos, and brand assets belong to their respective owners.

🚀 Live Demo
👉 https://abdnois.github.io/redbull-portfolio/

✨ Features
Product showcase — Energy, Sugarfree, and Zero cans with hover previews
Shopping cart — add/remove items, live badge count, slide-out drawer
Checkout page — order summary with payment method options
Fully responsive — mobile, tablet, and desktop layouts
Self-hosted images — all assets served locally (no hotlinking)
🛠️ Tech Stack
HTML5 — semantic markup
CSS3 — flexbox/grid layout, custom properties
Vanilla JavaScript — cart state, DOM rendering, no frameworks
GitHub Pages — static hosting
📁 Project Structure
redbull-portfolio/ ├── index.html # Homepage + product showcase ├── checkout.html # Checkout / order summary ├── css/ # Stylesheets ├── js/ │ └── main.js # Cart logic + product rendering └── assets/ # Self-hosted images (cans, logo, icons)


## 🧑‍💻 Run Locally

No build step needed — it's a static site.

```bash
# Clone
git clone https://github.com/Abdnois/redbull-portfolio.git
cd redbull-portfolio

# Serve (any static server works)
python -m http.server 8000
# then open http://localhost:8000

Or just open index.html directly in a browser.
